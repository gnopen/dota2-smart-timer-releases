# Dota 2 Smart Timer – releases

Download the latest installer from **[Releases](../../releases/latest)**:

- `Dota 2 Smart Timer-Setup-x.y.z.exe` – installer (updates itself automatically)
- `Dota 2 Smart Timer-x.y.z-portable.exe` – portable, no installation

Windows 10/11. The installers are not code-signed: on first launch SmartScreen may say "Windows protected your PC" → **More info → Run anyway**.

This repository contains only the release files used by the app's built-in updater. Not affiliated with or endorsed by Valve.
